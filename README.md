# Личный бренд под ключ

Универсальный проект построения личного экспертного бренда в соцсетях: от
анализа выбранной области до готового контент-конвейера с ежедневным сбором
тем, публикациями по расписанию и ежемесячной корректировкой. Подходит
экспертам, предпринимателям и специалистам любой сферы, которым нужна
репутация, приводящая клиентов, — а не «подписчики ради подписчиков».

Заказать стратегию под свою сферу: [zolmy.ru](https://zolmy.ru)

## Что получает клиент

- **Анализ выбранной области:** спрос на экспертный контент в нише, кто уже
  там говорит, какие углы не заняты, где сидит его аудитория
- **Выбор узкого направления:** одно флагманское позиционирование вместо
  расплывчатого «всё обо всём» — закрепить узко, расширять слоями позже
- **Площадки и форматы публикаций** — подобранные под аудиторию ниши и под
  то, что клиент реально готов делать (лицо в камеру, тексты, видео)
- **Систему сбора информации:** ежедневный поиск тем в копилку по рубрике
  отбора (спорность, эмоция, понятность новичку) — идеи копятся и ждут
  публикации, даже если на неделю пропало время
- **Ритм публикаций:** реалистичное количество постов в неделю под ресурс
  клиента (2–3 раза в неделю — устойчивый минимум), с датами контроля
- **Голос канала:** редполитика — на «ты», просто, без жаргона и ИИ-штампов
- **Конвейер с человеческим одобрением** (опция): инструмент, где бот
  показывает идею → черновик → публикация только по кнопке человека
- **Правовой фильтр по нише:** контент проверяется на соответствие закону
  «О рекламе» (38-ФЗ) и закону о персональных данных (152-ФЗ) — для
  регулируемых ниш (БАД, медицина, финансы) отдельный юридический модуль
- **Контрольные точки:** +2 недели, +1 месяц, +3 месяца, +6 месяцев от
  старта публикаций — сверка плана и факта, а не «постим и надеемся»
- **Метрики стадии роста:** на старте меряем входы (стабильность выпуска)
  и входящие обращения, не охваты
- **Ежемесячное сопровождение** (опция): опросник результатов → разбор
  месяца → корректировка рубрики и план на следующий месяц

## Пакеты

- **А — Стратегия:** анализ области, выбор узкого направления, стратегия на
  срок, контент-план на первый месяц, шапки профилей, юридическая памятка
- **Б — Стратегия + сопровождение:** всё из пакета А + ежемесячный цикл
  «опросник → корректировка → план на следующий месяц»
- **В — Стратегия + конвейер:** всё из пакета Б + настройка контент-конвейера
  под клиента: ежедневный сбор тем, бот одобрения, публикации по кнопке

## Примеры клиентских документов

Документы, которые заполняет клиент (в PDF — открываются на любом устройстве):

| Файл | Что это |
|---|---|
| `01_мини-опрос_клиента.pdf` | Семь коротких вопросов перед анализом области (5–10 минут) |
| `02_анкета.pdf` | Основная анкета: узкое направление, площадки, ритм, голос, ядро вопросов |
| `03_опросник_ежемесячной_корректировки.pdf` | Ежемесячный опросник результатов для сопровождения |

Личные данные не собираются: имя заменено номером заказа, город не
спрашивается, доход — только диапазоном.
